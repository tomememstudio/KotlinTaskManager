# Overview

The Kotlin Task Manager is a simple console-based application that helps users organize their tasks. Users can add new tasks, view their task list, mark tasks as completed, delete tasks, and view a summary of their progress.

I created this software to improve my software development skills and gain practical experience using Kotlin. The project helped me practise organizing code into functions, creating classes, working with mutable collections, using loops and conditional statements, and building an interactive menu with `when` expressions.

My goal was to develop a useful application while improving my understanding of Kotlin fundamentals and writing code that is organized, readable, and easy to maintain.

[Software Demo Video] https://youtu.be/Igc4SB6gpf8

# Development Environment

The tools I used to develop this software include:

* **Visual Studio Code:** Used to write and edit the Kotlin source code.
* **Kotlin Compiler:** Used to compile the program.
* **Java Development Kit (JDK 21):** Used to run the compiled Kotlin application on the Java Virtual Machine.
* **PowerShell:** Used to navigate project folders, compile the source code, and run the application.
* **Git and GitHub:** Used for version control and publishing the project repository.

The programming language used was **Kotlin**. The application uses Kotlin classes, mutable variables, immutable variables, functions, expressions, conditional statements, loops, a mutable list, and `when` expressions to manage tasks and respond to user input.
